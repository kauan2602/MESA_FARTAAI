# MESAFARTAI – Logística e Inteligência Assistiva no Combate à Fome

## Descrição do Projeto

O MESAFARTAI é um sistema desenvolvido em Python para conectar doadores de alimentos, como supermercados e restaurantes, a ONGs que precisam de doações.

O sistema utiliza Inteligência Artificial para compreender mensagens, identificar informações sobre os alimentos e ajudar a encontrar ONGs próximas para realizar as coletas.

O projeto está alinhado à **ODS 2 da ONU — Fome Zero e Agricultura Sustentável**, contribuindo para o combate à fome e a redução do desperdício de alimentos.
